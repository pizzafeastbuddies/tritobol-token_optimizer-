# Tritobol browser prototype

This is a framework-free, static UI prototype. Open `index.html` in a modern browser; no package installation or server is required.

The page demonstrates input, local UTF-8 file selection, tokenizer/budget controls, result and diff placeholders, an example truncation-warning state, and a separate-export affordance. It is **not integrated** with the Python package: clicking **Optimize text** reports that no optimization was run, statistics remain unavailable, and export is disabled. Local tokenizer selection is a UI affordance only and does not validate tokenizer compatibility.

The Costume Contest visual treatment is a proposal, not a confirmed category or final design direction.
