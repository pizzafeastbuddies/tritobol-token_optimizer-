Privacy and security

Where processing happens

On this computer. The optimizer is a Python program running next to this page; the server listens on 127.0.0.1 only and rejects requests addressed to any other host. Tokenizers run locally; the DeepSeek tokenizer is bundled with the app.

Is anything transmitted?

Prompt text makes no outbound network requests: no analytics, no web fonts, no CDN scripts, no model APIs. Your text goes from this page to the local server and back. The account email and password are stored in this installation’s SQLite database, not sent to an outside service.

What is stored

Prompt text is processed in memory and is not logged. Your browser stores settings and the numbers from recent runs. Prompt text is stored only after you tick the confirmation box on a result, and only in this browser. The SQLite database stores the account name, email, and password hash. It does not store prompt contents or uploaded documents.

Uploaded tokenizers

A tokenizer.json you upload is size-limited, validated by loading it, kept in memory only, and any temporary file is deleted straight away. Up to three are kept until the app stops.

Limits of sensitive-data detection

Tritobol looks for credential-shaped text using fixed patterns: well-known key prefixes for about a dozen providers (for example sk-, ghp_, github_pat_, AKIA, AIza, hf_) followed by a long run of key characters; assignments such as password = … or api_key: … with a value of 12+ characters; PEM private-key blocks; and CONFIDENTIAL:, INTERNAL ONLY: or DO NOT DISTRIBUTE: lines and BEGIN/END CONFIDENTIAL blocks.

This is not complete secret detection. Secrets in other formats, short values, secrets written in prose, personal data and anything not matching those patterns will not be found. In “Leave untouched” mode, found values stay in the optimized text; “Replace with [REDACTED]” masks only what was found. Always review text yourself before sharing it.

How it works

  1. Paste text or load a UTF-8 file in the optimizer.
  2. Tritobol counts tokens locally and applies its cleanup rules. A budget, if you set one, keeps the newest tokens and says when it truncates.
  3. Review the comparison, copy or export a new file, and optionally save the prompt on this computer.

Questions

Does Tritobol rewrite my prompt?

No. It removes repeated and low-value text. It does not summarize.

Do I need an account?

Yes, to open the dashboard. Get Started saves the account in this installation. There is no email verification step. Sign in with the password you chose.

Where does history go?

Statistics and any prompt you explicitly save stay in this browser. Export writes a file you choose. Nothing is uploaded.

About Tritobol

Tritobol is a local preprocessor for long prompts. The name is trim, token, and bolster: drop redundant text, count tokens with a tokenizer you can inspect, and keep the newest context when a budget requires a cut.

The approach is deterministic. The same input and settings produce the same cleanup. It is not a model, and it does not call a provider.

The same engine is available as a Python library and a command-line tool. An account on this installation opens the workspace. The account record does not include the prompt.
