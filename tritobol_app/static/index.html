What it does

Drops decorative separators, repeated paragraphs, lines and sentences, invisible characters and HTML comments. Fenced Python and JSON are only changed if the result still parses.

What a budget does

If you set a token budget and the trimmed text is still too long, the oldest tokens are discarded and the newest kept. That is truncation, not summarising — and you are always told when it happens.

Privacy and security

Where processing happens

On this computer. The optimizer is a Python program running next to this page; the server listens on 127.0.0.1 only and rejects requests addressed to any other host. Tokenizers run locally; the DeepSeek tokenizer is bundled with the app.

Is anything transmitted?

Tritobol makes no outbound network requests: no analytics, no web fonts, no CDN scripts, no model APIs. Your text goes from this page to the local server and back.

What is stored

The server keeps nothing: text is processed in memory and is not logged. Your browser stores settings and numeric run statistics automatically. The original prompt and optimized result are stored only if you choose “Save to history” and confirm; that text is kept in this browser profile's local storage at this app address, is not encrypted by Tritobol, and is not synced to other devices. Clear saved prompts in Prompt history or erase run statistics in Settings. A file is written only when you press an export button, and always as a new file.

Uploaded tokenizers

A tokenizer.json you upload is size-limited, validated by loading it, kept in memory only, and any temporary file is deleted straight away. Up to three are kept until the app stops.

Limits of sensitive-data detection

Tritobol looks for credential-shaped text using fixed patterns: well-known key prefixes for about a dozen providers (for example sk-, ghp_, github_pat_, AKIA, AIza, hf_) followed by a long run of key characters; assignments such as password = … or api_key: … with a value of 12+ characters; PEM private-key blocks; and CONFIDENTIAL:, INTERNAL ONLY: or DO NOT DISTRIBUTE: lines and BEGIN/END CONFIDENTIAL blocks.

This is not complete secret detection. Secrets in other formats, short values, secrets written in prose, personal data and anything not matching those patterns will not be found. In “Leave untouched” mode, found values stay in the optimized text; “Replace with [REDACTED]” masks only what was found. Always review text yourself before sharing it.
